## Data

- **Base:** `seed-demo` ran on 2026-10-30 (the screenshots were redone that day, after UX batch 4, on a fresh database). It creates 5 owners, 60 players, 10 clubs, 43 pitches, 5 blocks and about 10,400 bookings, which cover the previous 60 days and the next 14, that is, from 2026-08-31 to 2026-11-13. All addresses are `example.test` and the password of the demo accounts is the one in the README.
- **Periods used:** the statistics (`screenshot-owner-statistics-club`, `screenshot-admin-dashboard` and `screenshot-admin-top-occupation-registrations`) use 09/09/2026 to 10/10/2026, a range entirely inside the data. The dates of `screenshot-club-search-results`, `screenshot-club-page-slots-and-prices`, `screenshot-booking-summary-weekly-repeat` and `screenshot-owner-calendar-day` are 11/11/2026 (12 days later), which the seed already fills.
- **Added by hand after the seed**, through the API and the interface with demo accounts, to show features the seed does not create: a price band on Futsal A of Arena Futsal Boavista (Monday to Friday, 18:00–00:00, €46.00); the weekly series of `jogador01@example.test` (Wednesdays 11, 18 and 25 November at 21:00), created through the interface itself with `Confirmar 3 reservas` (Confirm 3 bookings) right after the `screenshot-booking-summary-weekly-repeat` capture (so `screenshot-my-bookings-upcoming-series` already shows it and `screenshot-booking-summary-weekly-repeat` still shows the three dates free); a block on Padel 1 of Lisboa Padel Club (11 November, 09:00–12:00, reason `Manutenção da iluminação` (Lighting maintenance)); and a booking for the demo customer "Rui Teixeira" on Padel 2 (15:00–16:30).
- **Dates whose day equals the month** (11/11, 09/09, 10/10): Chromium's date field without a pt-PT interface is displayed in month/day order; with these dates the reading is the same in both orders.

## How they were made

The full stack with `docker compose` in a separate project, `seed-demo`, and Chromium with Playwright (outside the repository, not included): 1440 px window, `Europe/Lisbon` time zone, `pt-PT` language, light theme (the application has no dark theme), production build (no development overlays). Each PNG was reduced to a palette of 128 colours and checked by eye: only demo data appears, with no secrets, tokens or browser frame.

The capture script is not in the repository. Whoever captures again writes to `docs/images/`, with the name `screenshot-<name>.png` from the table above (the folder used to be called `docs/screenshots` and the files carried a number in front).
